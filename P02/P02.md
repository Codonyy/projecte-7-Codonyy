
# P02: Web corporativa

## Breu descripció

### Introducció

A la tasca 8 vau triar quina seria la proposta de pàgina web que presentareu davant els responsables de **FoodLogístics** per substituir la seva pàgina actual. Toca, doncs, desplegar aquesta solució perquè sigui visible pel client.

## Descripció de l’activitat

En primer lloc, creeu-vos el repositori corresponent a la tasca `web_projecte7`. L’enllaç el teniu al Moodle de Projecte Intermodular (**P02 Web Corporativa**).

Un cop el tingueu creat:

1. Cloneu el repositori en local.
2. Completeu la informació de l’arxiu `README.md`.
3. Creeu una carpeta anomenada `/docs`.
4. Dins d’aquesta carpeta, copieu el codi corresponent a la pàgina web que voleu presentar al client.

Un cop hàgiu confirmat els canvis (*commit*) i els hàgiu pujat a GitHub (*push*), configureu el desplegament a **GitHub Pages** del contingut de la carpeta `docs`.

Cal que tots els membres de l’equip realitzin aquest procés als seus respectius repositoris.

## Objectius específics de la tasca / Finalitat de la tasca

* Desplegar un servei web a GitHub Pages.
