
# T02: Creant la proposta de pàgina corporativa

## Breu descripció

Disseny, publicació i monitorització d’una proposta de web corporativa per a **FoodLogístic S.A.** utilitzant GitHub Pages.

---

## Introducció

La web actual del client està desactualitzada i no compleix la normativa vigent.

Per aquest motiu, es desenvolupa una nova proposta que sigui:
- Moderna
- Funcional
- Legal (LOPDGDD i LSSI-CE)

---

## Objectius

### 🌐 Publicació professional

- Crear una web funcional amb:

GitHub Pages

- Publicar-la amb una URL pública

---

### 📄 Documentació

- Crear un fitxer:

README.md

- Explicar:
  - El projecte
  - L’empresa
  - L’autor

---

### 📊 Analítica web

- Integrar eina de monitorització:

StatCounter

- Obtenir dades de:
  - Visites
  - Usuaris
  - Activitat

---
