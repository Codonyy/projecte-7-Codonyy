
# P03: Repositori personal

## Breu descripció

### Introducció

L’ús de GitHub i el control de versions mitjançant Git ja és una tècnica que hauríeu d’haver interioritzat. Per tant, no us ha d’estranyar que el repositori de GitHub sigui la base del lliurament del projecte.

A la tasca inicial del projecte vau crear el vostre repositori a partir del repositori base proporcionat. Ara toca comprovar que el teniu llest per al lliurament.

Recordeu que cada projecte i producte ha de tenir la seva carpeta seguint un criteri de nomenclatura com ara `T01`, `T02`, `P01`, `P02`, etc.

Dins de cada carpeta hi ha d’haver un arxiu anomenat `README.md` (exactament amb aquest nom), on incloureu una descripció de l’activitat, que pot correspondre a una versió resumida de l’enunciat. És important que el document estigui en format Markdown i que estigui estructurat en seccions.

La solució s’ha de trobar en un arxiu anomenat `solucio.md`, que inclogui el codi, les explicacions o els enllaços necessaris. Les imatges s’han d’emmagatzemar dins d’una carpeta específica.

## Què cal lliurar

* Repositori assignat al GitHub Classroom.

> No s’acceptaran lliuraments en repositoris diferents dels assignats a GitHub Classroom.
